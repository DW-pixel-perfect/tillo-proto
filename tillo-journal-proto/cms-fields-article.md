# Поля CMS для статьи (на основе `tillo_journal_article_sleep_guide.html`)

Разбор сущностей, которые встретились при вёрстке статьи «Как заснуть за 10 секунд, за минуту или за две» — как основа для модели контента статьи в CMS. Часть полей уже была в шаблоне `tillo_journal_article_news.html`, часть добавлена под эту статью (callout, note-предупреждение, видео из Instagram).

## 1. Классификация

| Поле | Тип | Комментарий |
|---|---|---|
| Категория | select | Новости / Гайды / Статьи |
| Тег/рубрика | select или tags | напр. «Сон», «Питание», «Психология», «Спорт и тело» (см. фильтры на `tillo_journal_category_guides.html`) |
| Тип разметки (schema.org) | select | Article / NewsArticle / … — влияет на SEO-панель |

## 2. SEO / OG (служебные, не отображаются на странице)

| Поле | Тип |
|---|---|
| SEO title | текст |
| SEO description | текст |
| Slug (URL) | текст |
| OG title | текст |
| OG description | текст |
| OG image | изображение |

## 3. Заголовок и вступление

| Поле | Тип | Комментарий |
|---|---|---|
| Заголовок (H1) | текст | |
| Лид / подзаголовок | текст | короткое summary под заголовком |
| Хлебные крошки | авто + override | по умолчанию строится из категории, но нужен текст последнего пункта («Как быстро заснуть») |

## 4. Обложка (featured image)

| Поле | Тип | Комментарий |
|---|---|---|
| Изображение | файл | |
| Alt-текст | текст | для доступности/SEO |
| Фото-кредит | текст | напр. «Фото: Грег Паппас, Unsplash» — в тексте-источнике кредит указывался отдельно от alt |

## 5. Мета публикации

| Поле | Тип | Комментарий |
|---|---|---|
| Автор | связь с профилем | в этой статье — «Редакция Tillo», не персональный автор |
| Дата публикации | дата | в исходном тексте не указана — обязательное поле, требует значения перед публикацией |
| Дата обновления | дата | |
| Экспертная проверка (баннер) | текст + связь | имя, должность, клиника/организация; свой toggle показать/скрыть баннер отдельно от автора |

## 6. Блоки тела статьи (контент-констрyктор)

Порядок и набор блоков — свободный (drag&drop), но должны поддерживаться минимум такие типы:

| Блок | Поля | Комментарий |
|---|---|---|
| Параграф | rich text | обычный текст |
| Заголовок раздела | текст + уровень (H2/H3/H4) | нужно 3 уровня вложенности — в статье это разделы → подтехники → точки акупрессуры |
| Маркированный список | список текстовых пунктов | шаги упражнений, чек-листы, причины |
| Изображение в теле | файл + подпись/кредит | в статье повторяется несколько раз с разными кредитами (Levi Stut, Dane Wetton, Cate the Kitty) |
| Видео | ссылка + платформа (YouTube/Instagram/Vimeo) + подпись | в исходнике — редакторская пометка «вот тут бы видео врезать» + ссылка на Instagram Reels |
| Выделенный блок / callout | rich text (может включать список) | в исходнике помечено как «выделение цветом… /конец выделения цветом» — чек-лист перед началом техник |
| Предупреждение / медицинская заметка | текст, возможно иконка | напр. предостережение про астму/ХОБЛ перед дыхательными практиками с задержкой дыхания |

## 7. Отключаемые блоки в конце статьи (toggle-blocks)

Каждый — с отдельным тумблером «показывать на странице»:

| Блок | Поля |
|---|---|
| Карточка исследования | название, журнал, дата, DOI/ссылка, тип исследования, размер выборки, ограничение |
| Источники | список: заголовок источника, издание, дата, ссылка/DOI |
| Связанные статьи | 1–3 карточки: изображение + заголовок + ссылка (ручной выбор или авто по тегам) |
| Блок автора | аватар, имя, био, ссылка на профиль |
| CTA (подписка/партнёрство) | заголовок, текст, текст кнопки, ссылка кнопки |

## 8. Системные поля (стандартные для любой статьи в CMS)

- Статус: черновик / на проверке / опубликовано
- История версий / кто и когда редактировал
- Автор публикации (учётная запись в CMS, может отличаться от «Автора» статьи)

---

### Что не удалось заполнить из исходника (нужно уточнить у автора/редакции)

- Дата публикации/обновления — не указана в тексте.
- Источники и исследования упоминаются без названий/ссылок (кроме общей отсылки к «исследованию Оксфордского университета» и легенде про книгу «Расслабься, чтобы победить») — в статье и в этом файле оставлены как `[добавить ссылку]`, чтобы не выдумывать несуществующие DOI/названия.
- Alt-текст для фото не указан отдельно от кредита — в исходнике шли только подписи вида «Фото: Имя, Unsplash».
